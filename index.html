DNS

El DNS (Domain Name System) tradueix noms com www.exemple.com a adreces IP com 93.184.216.34.

  • Per què serveix? Per no memoritzar IPs i facilitar la navegació.
  • Port: 53 (UDP normalment; TCP en casos concrets, com transferències de zona).
  • Registres típics: A/AAAA, CNAME, MX, TXT.

DHCP

El DHCP assigna automàticament IP, màscara, gateway i DNS als equips d’una xarxa.

  • Avantatge: evita configurar IP manualment a cada dispositiu.
  • Port: 67 (servidor) / 68 (client) sobre UDP.
  • Procés: Discover → Offer → Request → Ack (DORA).
Exemple: un portàtil es connecta al Wi-Fi i rep IP en segons.

FTP

El FTP (File Transfer Protocol) és un protocol per pujar i baixar fitxers a un servidor.

  • Ús: publicar webs, compartir arxius, manteniment de servidors.
  • Port: 21 (control). Pot usar ports addicionals per dades.
  • Seguretat: FTP “clàssic” no xifra; alternatives: SFTP (via SSH) o FTPS.
Transferència d’arxius No xifrat (FTP) SFTP recomanat

SSH

El SSH (Secure Shell) permet administrar equips remotament amb connexió xifrada.

  • Ús: entrar a un servidor Linux, executar comandes, copiar fitxers (scp/sftp).
  • Port: 22 (TCP).
  • Autenticació: contrasenya o (millor) clau pública/privada.
Exemple: gestionar un servidor sense pantalla (headless) des del teu PC.

HTTP

HTTP és el protocol base del web: el navegador demana recursos (HTML, CSS, imatges) i el servidor respon.

  • Port: 80 (HTTP) / 443 (HTTPS, xifrat amb TLS).
  • Mètodes: GET (llegir), POST (enviar dades), etc.
  • Estàtic vs dinàmic: aquesta pràctica és una web estàtica (fitxers).
